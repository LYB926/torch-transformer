# torch-transformer
PyTorch implementation of Transformer from "Attention is All you Need", running on Google Colab.

## Getting Started

### Linking Your Local Repository to This Remote Repository

If you have a local repository and want to link it to this remote repository, use the following command:

```bash
git remote add origin https://github.com/LYB926/torch-transformer.git
```

To verify the remote has been added successfully:

```bash
git remote -v
```

After linking, you can push your local changes to this repository:

```bash
git push -u origin main
```
